# Import from a BibTeX File

The publications module lets you import a batch of publications by uploading a BibTeX (`.bib`) file. This format is exported by most reference managers such as Zotero, Mendeley, or EndNote.

## Exporting a BibTeX file from your reference manager

Before importing, export your publications in BibTeX format from your reference manager. Consult your software's documentation for the export procedure.

## Accessing the BibTeX import

From the module home page, locate the **Import** menu, then select the **BibTeX** option.

<figure markdown>
  ![BibTeX import option](../assets/screenshots/bibtex-option.png)
  <figcaption>Select "BibTeX"</figcaption>
</figure>

## Uploading the file

Click the file selection button and choose your `.bib` file from your computer, or drag and drop the file into the drop zone.

<figure markdown>
  ![BibTeX file selection](../assets/screenshots/bibtex-upload.png)
  <figcaption>Select your .bib file</figcaption>
</figure>

## Reviewing the detected publications

The module parses the file and displays the list of detected publications. Publications already in your list will be flagged and skipped to avoid duplicates. Click **Continue import**.

<figure markdown>
  ![Preview of publications to import](../assets/screenshots/bibtex-preview.png)
  <figcaption>List of publications detected in the BibTeX file</figcaption>
</figure>

## Importing publications one by one

Locate the publication you want to import, then click **Import**.

<figure markdown>
  ![Importing publications one by one](../assets/screenshots/bibtex-onebyone.png)
  <figcaption>Import publications one by one</figcaption>
</figure>

## Validating entries

You will be redirected to the pre-filled creation page. Review each entry and click **Create**. You will then be redirected back to the import page. Repeat these two steps for each publication to import.

<figure markdown>
  ![Validating entries](../assets/screenshots/bibtex-onebyone.png)
  <figcaption>Validate each entry and click "Create"</figcaption>
</figure>

## Finishing the import

When all publications in the file have been imported, you will be automatically redirected to the module home page. To finish the import manually, click **Finish import**.

<figure markdown>
  ![Finish import](../assets/screenshots/bibtex-end-import.png)
  <figcaption>Click "Finish import"</figcaption>
</figure>
